# 高考高分的意义

对于绝大多数同学来讲，高中有着一个非常“简单”并且单一的目的：考个好分数，上个好大学。但是我敢笃定的是，绝大多数同学并不知道高考分数意味着什么，甚至是一个好的学历意味着什么。所以，既然考高分是你高中的一大重要任务，那我们很有必要知道这么做是为了什么。

容我先问你个问题，在我以下列出的几条中，哪一个是你想考一个**好的**大学的原因？

- [ ] 不负父母/老师的期待
- [ ] 向同学证明自己
- [ ] 我不到啊，大家都这么做
- [ ] 赚很多钱
- [ ] 过上自己想过的生活
- [ ] 有能力为社会做贡献

每个选择并没有对错。但是我想说的是，如果你真的考了一个好大学（当然我也希望你如此），前面两条是很容易的，但是后面三条仍然很困难。

有的同学肯定要生气了：你是在和我说读书没有用吗？放心放心，我当然不会跟你鼓吹“读书无用论”，我觉得你在高中认真读书是非常有必要的。但是，我不得不破解一些误区，这些误区不仅仅会影响你的高中学习，更有可能持续到你的大学生涯，对你的人生造成不良影响。
