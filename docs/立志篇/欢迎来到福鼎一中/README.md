# 欢迎来到福鼎一中

恭喜你考入福鼎市第一中学。这确实很值得祝贺——因为你成为了福鼎市学习成绩最优秀的学生之一。

你不同于福鼎市别的中学的学生，因为你有大约0.4%的概率考上清北、5%的概率考上985高校、12%的概率考上211高校，而在福鼎市别的高中，这些概率几乎都是 **0** ！

这里拥有 69% (2024) 的一本率（超过[特控线](https://m.gaokao.cn/zd/139748)），将近100%的本科率，你在福鼎其他任何一所高中都不会有这样优质的教育资源。我们福鼎一中确实相当厉害，难道不是吗？

屏幕前的你，是否是一个在初中发奋图强，在中考中脱颖而出的佼佼者呢？还是你只不过在初中玩一玩，轻轻松松就进入了福鼎一中？当你看到你的中考成绩，又或是收到福鼎一中的录取通知书，你是认为这一切理应属于自己，还是认为自己终于不负期盼自己成才已久的父母，又或者已经在期待着美丽的校园生活？

你是否想过，你要在高中完成怎么样的人生目标？是考上一所理想的高校，还是钻研自己的兴趣，又或者只想舒舒服服地度过高中？

再往远处看，你希望在你20岁、30岁、甚至是60岁，回忆起你的高中生活，希望其给你带来了什么？

路还很长很长...
